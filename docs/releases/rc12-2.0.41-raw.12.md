# Hardened NanoKVM 2.0.41 RC12 + System 0.3.0 Raw 12

> RELEASE_BLOCKED_PENDING_SIGNING_AND_REDISTRIBUTION
>
> Binary publication is prohibited until the existing trusted private update
> key is made available through approved custody and a redistribution grant is
> recorded for every retained vendor firmware/runtime input. Generating a new
> uncoordinated key or adding an experimental-use disclaimer does not satisfy
> these gates.

## Required install order

Existing installations must update the application to **2.0.41 first**, verify
that version in the web UI, and only then enable the **Preview** system channel
and install system **0.3.0-raw.12**. Format-2 system metadata enforces
`required_app_version: 2.0.41`.

Do not install the raw system payload first. The full SD-card image already
contains application 2.0.41 and does not need a separate app-first step.

## Application 2.0.41 RC12

- Includes the audited native C/C++ fixes and the current Rust backend/web UI.
- Retains signed update metadata and exact archive verification.
- Adds the format-2 app-first checks required by Raw 12.
- Existing Raw 10 installations may install this app independently before
  deciding whether to try the new Buildroot/kernel system image.

## System 0.3.0-raw.12

- Uses Buildroot `2026.05.1` with the accepted Raw 11 userspace security
  maintenance carried forward.
- Replaces the retained vendor kernel `5.10.4-tag-` with Linux
  `5.10.265-tag-`, based on Linux stable plus the reviewed SG2002 vendor port.
- Enables restricted `dmesg`, disables user namespaces, enables SLUB freelist
  randomisation, and enables heap initialization on allocation.
- Leaves SLUB pointer hardening and init-on-free disabled because they were not
  accepted in this release scope.
- Rebuilds all 57 runtime modules against the selected kernel and records their
  exact source provenance.

- Two clean final raw.12 pipelines from build commit `34cb2cb` are byte-exact
  through kernel, modules, Buildroot rootfs, FIT and compressed full SD image.
  The selected `.img.xz` SHA-256 is
  `23df0435fb81d762fcc55483e7159cb7022e150dd03935d42f480671e1d3e546`.
- Exact device identity, functional runtime, the predeclared performance gate,
  ten software reboots and rollback to the accepted prior kernel pass with zero
  kernel alerts.
- During the candidate run the test device had no active HDMI input and no Wi-Fi

  HDMI/Wi-Fi/HID matrix; this release does not present that waiver as new
  positive hardware evidence.
- The exact selected full SD image passed initial boot, storage expansion,
  identity/runtime checks and two post-expansion reboots on test hardware with
  zero kernel alerts.

## Recovery and limitations

- Raw 12 rewrites the boot and rootfs partitions. Keep a verified recovery SD
  image and physical card access available before starting.
- Raw partition installation has no general-purpose automatic rollback script.
  Failure recovery is by the documented physical SD reflash/recovery process.
- The full SD image is the recommended way to evaluate the new Buildroot and
  kernel combination on a spare or recoverable card.
- This release does not claim that the SG2002 vendor delta is free of every
  upstream kernel CVE; it reports the exact stable base, configuration,
  backports, provenance and tested gates instead.
- Several required vendor firmware/runtime inputs still carry `NOASSERTION`
  metadata and explicit `redistribution=disabled-pending-license-grant`
  provenance. This draft is not authorization to distribute those binaries.
